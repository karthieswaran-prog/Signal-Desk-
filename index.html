Import guidelines

How records are handled
Record identity
Records are matched using the combination of source type and source ID. If a record has no source ID, a fallback identity is generated from its available identifiers.
Revision handling
When multiple versions of a record are imported, the higher numeric revision takes precedence. Identical or older revisions are not allowed to overwrite newer data.
Data preservation
Manual routing choices and manager notes are preserved when source records are updated, unless the record's identity changes.
Supported structures
The importer accepts a JSON array or an object containing a common collection such as records, conversations, messages, items, or data. Review the imported record count and sample records after each import.
